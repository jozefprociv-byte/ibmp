## Як виставити на Netlify (безкоштовно)

1. Отримай безкоштовний ключ Gemini: https://aistudio.google.com/apikey → Create API key (картка не потрібна).

2. Зайди на https://app.netlify.com → Add new site → Import an existing project → GitHub → вибери репозиторій **ibmp**.

3. У Site settings → Environment variables додай:
   - `GEMINI_API_KEY` = твій ключ
   - `APP_PASS` = `ckvCYeKgZ46MkaYv`

4. Deploy site.

5. Відкрий посилання на телефоні → «Встановити додаток».
   Код доступу при першому запуску: `ckvCYeKgZ46MkaYv`

Все безкоштовно.
